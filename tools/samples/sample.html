The Companion Mode Deck

How Spatial Deck and Claude Design plug into each other.

  • Claude Design owns the brand system — typography, tokens, palette.
  • Spatial Deck owns the runtime — animation, navigation, audio.
  • Importers are the bridge.

How the handoff works

Ship a CSS file and an HTML outline. We parse both.

  1. Tokens CSS flows through import_tokens.py to :root{}.
  2. HTML outline flows through import_html.py to SECTIONS.
  3. The merger splices the chapter between sentinel comments.
